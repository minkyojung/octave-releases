# Octave releases

Downloads for [Octave](https://www.octave.run), and the place to report a problem with it.

- **Download:** the [latest release](https://github.com/minkyojung/octave-releases/releases/latest).
- **Report a problem:** [open an issue](https://github.com/minkyojung/octave-releases/issues/new).

This repository holds the built app only. It carries no source code.
